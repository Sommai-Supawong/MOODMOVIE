# Local artwork

The 24 SVG posters are original geometric interpretations created for this demo,
not official theatrical artwork. They use system fonts, vector shapes, and no
remote assets. Film titles identify the catalog entries. Rebuild them using
`python scripts/build_posters.py` after installing the project dependencies.

`poster-fallback.svg` is the local image-error fallback. The favicon is a local
typographic mark. No image API, font CDN, or network connection is needed at runtime.
